# CITYFLOW 지도 표시 규칙 (v4)
- 정상 운행 경로: 옅은 회색 실선
- 우회 반영 최종 경로: 탑승 노선마다 색이 다른 실선 (환승하면 색 변경)
- 도보: 회색 점선 (같은 정류소 환승 0m 도보는 생략)
- 정상·최종 경로는 좌우 4px 떨어뜨려 표시
- [v4] 초기 화면에는 정류소 표시 없음
- [v4] 정상 경로의 무정차 정류소: 회색 ✕ / 우회 경로의 미정차 정류소: 해당 구간 노선 색 ✕ (검색 결과에만)
- 추정값은 '추정', 미확인 통제는 '확인 필요'. 조건 C 하한 속도 기본 80km/h(변경 가능)
