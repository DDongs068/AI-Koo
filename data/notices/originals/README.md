# 공지 원본 첨부 (originals)

`topis_v1_*.csv` 에 반영된 공지의 **TOPIS 첨부 원본**(PDF·hwpx·xlsx·hwp)입니다. 노선별 우회 지도 HTML 등을 만들 때 쓰세요.

- `index.csv` — 공지 목록. 공지ID, **종류**(우회 / 무정차 / 우회+무정차), 제목, 행사 기간, 원문 링크, 첨부 파일 경로.
- `<공지ID>/` — 그 공지의 첨부 파일. **첨부가 없는 공지는 폴더가 없고, index.csv 의 첨부파일 칸이 비어 있습니다**(글로만 적힌 공지).
- 종류는 공지 제목의 '우회'·'무정차' 글자로 나눈 것입니다. 우회 지도가 필요한 공지는 종류가 '우회' 또는 '우회+무정차' 인 것입니다.
- 첨부가 있어도 .hwp 는 우리 쪽에서 내용을 읽지 못해 CSV 에 반영되지 않았을 수 있습니다.
- 지난 행사는 하루 뒤 자동으로 지워집니다. 필요하면 받아서 따로 보관하세요.
